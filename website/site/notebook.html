What the notebook is for

The work

The completed and in-progress writing this notebook exists to carry — working memory and findings — with everything below as the evidentiary floor it rests on. Bracketed ids in the prose link to the claims and sources further down.

Custody & judgment

Sources

What the notebook actually captured and how each source was judged. Grade is derived from independence and basis; freshness says when it was last checked; provenance says how it arrived; custody says whether the captured bytes are held in the notebook.

id title grade independence basis freshness provenance custody

What this notebook asserts

Claims

A claim enters asserted. Sources name what it rests on; corroboration counts independent witnesses; exposure summarizes the tests it has faced; verifications record successful checks. It cannot call itself verified until the corroboration bar is met — mechanically, not by anyone insisting — and a severe test that found the error closes that gate again whatever the count says. exposure is derived from the test record on read, never stored; a claim citing only the document it is about reads n/a (subject) rather than zero, because there the corroboration question does not apply.

id claim status load-bearing value sources corroboration exposure verifications

Open threads

Questions

An open question without a watching surface is a wish, not a plan — flip marks it unwatched rather than pretending it is covered.

    What this page is

    Nothing above was typed by a person for this site. The notebook it renders was scaffolded, sourced, graded, claimed, decided, and logged by the real flip CLI during the site build — the flipbook page shows the reporting conversation that produced the same notebook; this page shows the durable record once the investigation is whole. The projection itself is versioned: this page reads flip-render/2, the contract flip export json --render-version 2 emits, so a future contract bump cannot silently change what a reader sees here without the build noticing first.
