Claims

A claim enters asserted. It cannot call itself verified until the corroboration bar is met — mechanically, not by anyone insisting — and a severe test that found the error closes that gate again whatever the count says. exposure is derived from the test record on read, never stored; a claim citing only the document it is about reads n/a (subject) rather than zero, because there the corroboration question does not apply.

    What this page is

    Nothing above was typed by a person for this site. The notebook it renders was scaffolded, sourced, graded, claimed, decided, and logged by the real flip CLI during the site build — the flipbook page steps through the same notebook one command at a time; this page shows where all those commands land once the notebook is whole. The projection itself is versioned: this page reads flip-render/2, the contract flip export json --render-version 2 emits, so a future contract bump cannot silently change what a reader sees here without the build noticing first.
