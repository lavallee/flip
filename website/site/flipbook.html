The flipbook

One prompt becomes a reporting notebook

The person asks one research question. The agent scopes it, follows the origin trail, runs down gaps and counter-evidence, and returns an answer. That is the conversation. flip works underneath: capturing sources, testing claims, preserving the missing pieces, and leaving a notebook another agent can pick up. Open any Under the hood panel when you want the commands and records; ignore them when you only want the reporting.

This walkthrough is distilled from a real, completed investigation of the Open Knowledge Format. Its compact source packets keep the docs build offline; every command, output, file change, and record shown here is regenerated with the real CLI. The full public notebook retains the original captures and the conversation-level transcript.

What this run is meant to show

The agent did more than collect agreeable links. It separated the direct LLM-wiki precedent from a deeper, second-order Memex lineage; found that OKF's first public repository commit was a snapshot that omitted the upstream history; and kept that missing history visible rather than smoothing it out of the answer.

It also held different kinds of findings differently. Statements about what a single document says were tested against that captured document. The gap map needed several independently authored proposals. The negative roadmap finding names the repository surfaces checked and excludes a project board the run could not observe. A separate claim records the planning signals that were found. "No roadmap here" never becomes "no planning anywhere."

The result is still a directory of Markdown files plus append-only ledgers. Read the compact build-time version on the notebook page, or browse the full rendered notebook with all original captures, judgments, claims, questions, and the transcript.
